# Number Guessing Game 🎮

A Python-based command-line game where the user attempts to guess a randomly generated number.

## 📌 Features
- Random number generation logic.
- Input validation (handles errors if you type text instead of numbers).
- Attempt counter to track your score.

## 🔧 How to Run
1. Ensure you have Python installed.
2. Clone this repository.
3. Run the command: `python game.py`

## 📚 What I Learned
By building this project, I practiced:
- Python `while` loops and control flow.
- Using the `random` module.
- Handling user inputs and Type Casting.
